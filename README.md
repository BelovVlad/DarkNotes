# DarkNotes

Самостоятельное локальное веб-приложение для рукописных конспектов и аннотаций PDF. React, TypeScript, Vite, Canvas 2D, perfect-freehand, PDF.js, pdf-lib, Dexie/IndexedDB и Radix UI. Распознавания рукописного текста, OCR, отправки записей на сервер и облачной учётной записи нет.

Оформление основано на CSS [вашего основного сайта NSU FP](https://belovvlad.github.io/NSU_FP_Y4_S1/docs/): `#080d12`, `#0e151c`, кремовый `#ead4b7`, красный `#d64c50`, системный шрифт интерфейса. Код основного сайта не изменялся.

## Запуск в этой папке на Windows

Откройте **Start-DarkNotes.cmd** двойным щелчком. После сборки откройте **http://localhost:4173**. Окно запуска должно оставаться открытым; остановка — `Ctrl+C`.

В `.tools` подготовлен переносимый Node.js 22, поэтому глобально устанавливать Node для этой копии проекта не требуется. Скрипт не меняет системный PATH. Для переноса проекта на другой компьютер установите Node.js 22.13+ или более новую LTS-версию.

Из PowerShell:

```powershell
# Готовая сборка с PWA и офлайн-режимом
.\Start-DarkNotes.ps1 -Production

# Разработка с горячим обновлением
.\Start-DarkNotes.ps1
```

Со стандартным Node.js:

```sh
npm ci
npm run dev
```

Для проверки PWA используйте сборку, а не сервер разработки:

```sh
npm run build
npm run preview -- --port 4173
```

Разработка открывается на `http://localhost:5173`, сборка — на `http://localhost:4173`. Хранилища этих адресов независимы. Для повседневного использования держите один адрес и браузер. Перенос между адресами — через резервную копию.

## Что работает

- Библиотека без демонстрационных документов: создание тетрадей, обложки, A4/A5/Letter/квадрат, ориентация, цвет бумаги, чистая бумага/клетка/линейка/точки.
- Вложенные папки, сворачивание дерева, перенос папок и документов мышью, переименование, дублирование, цветовые маркеры, перемещение через меню, поиск **по названиям**, сортировка, сетка/список, групповой выбор, недавние и избранное.
- Корзина с восстановлением. Окончательное удаление требует отдельного действия внутри приложения.
- Ручка, шариковое и перьевое перо, цвет, размер, непрозрачность, избранные пресеты. Давление, наклон и время точек сохраняются; наклон пока не изменяет форму пера.
- Маркер с полупрозрачным наложением. Обычный ластик по умолчанию стирает часть линии; объектный удаляет штрих, текст или изображение целиком. Быстрое движение ластика обрабатывается по всей траектории. Параметры открываются нажатием на выбранный инструмент.
- Лассо произвольной формы и прямоугольное выделение. Перемещение меняет реальные координаты. Масштабирование, изменение цвета, копирование, вырезание, вставка и удаление нескольких объектов. Буфер объектов работает между страницами в текущей сессии.
- Прямые линии, прямоугольники, овалы, стрелки, изображения PNG/JPEG/WebP, многострочные текстовые блоки. Для редактирования текста снова нажмите на него инструментом «Текст».
- История Undo/Redo на 80 состояний в текущей сессии, в том числе после возврата в библиотеку и повторного открытия тетради.
- Circle to Lasso: обводка с удержанием без отрыва и повторное нажатие с удержанием на уже нарисованном контуре. Долгое нажатие на объект показывает выделение с панелью действий.
- Scribble to Erase: быстрое многократное зачёркивание пересечённых рукописных штрихов. Геометрические эвристики, без анализа букв. Отключается в настройках; удаление можно отменить.
- Удержание после рисования выравнивает линию, прямоугольник или овал. Выделение объектов имеет приоритет над выравниванием фигуры.
- Навигация двумя пальцами, щипок относительно точки между пальцами, двойное короткое касание **двумя пальцами два раза** для отмены. Мышью — инструмент «Перемещение», колёсико, Ctrl/⌘ + колёсико. Двойное касание или двойной щелчок в режиме перемещения меняет масштаб.
- Постраничный и непрерывный просмотр, ленивое создание слоёв страниц, миниатюры, переход по номеру, закладки, вставка чистой страницы, дублирование, поворот и удаление страниц.
- Импорт PDF, рисование поверх исходного документа, поиск **по существующему текстовому слою PDF**, выделение и копирование печатного текста. Сканированные PDF без текстового слоя доступны для просмотра и рисования; OCR нет.
- Экспорт PDF с выбором «Тёмный DarkNotes» / «Белый для печати» и отключением разметки. Штрихи, бумага и текстовые блоки сохраняются векторами, кириллический шрифт встраивается. Размер страницы и поворот сохраняются. Исходный PDF переносится с текстовым слоем, если не требуется менять его цветовую тему.
- Экспорт отдельного редактируемого проекта `.darknotes` и всей библиотеки с исходными PDF, папками и настройками. Восстановление проверяется до записи и выполняется одной транзакцией.
- Светлая, тёмная и системная темы. Бумага по умолчанию следует теме: `#0e151c` / белый. Шесть пар цветов чернил автоматически адаптируются в обе стороны; исходные объекты не перезаписываются. Свой цвет бумаги можно закрепить отдельно.
- Плавающая панель рисования: перетаскивание за рукоятку мышью, пальцем или пером; сворачивание; сохранение положения; ограничение по краям экрана после поворота. При фокусе на рукоятке стрелки перемещают панель, Shift ускоряет, Home возвращает начальную позицию. Инструменты вставки открываются рядом и остаются внутри экрана.
- Меню файлов на Radix UI: управление клавиатурой и касанием, закрытие по Escape, возврат фокуса, доступные названия цветов обложки.
- Компактный редактор для обеих ориентаций планшета: миниатюры скрыты при входе, фигуры и вставка находятся в меню «+», настройки пера всплывают поверх листа. Режим письма скрывает заголовок и нижнюю строку. При повороте планшета лист подстраивается по ширине, пока масштаб не изменён вручную.
- Устанавливаемая PWA с manifest, PNG-иконками и Service Worker. После первоначальной загрузки сборки приложение и ресурсы PDF.js доступны без сети. Обновление предлагается кнопкой и не удаляет IndexedDB.

## Как хранятся данные

IndexedDB `darknotes-v1` содержит отдельные хранилища `documents`, `previous`, `folders`, `assets`, `settings`. PDF хранится как исходные двоичные данные ArrayBuffer, отдельно от массива страниц и объектов. Старые записи Blob читаются без конвертации. Dexie обновляет исходную базу на месте: прежние документы, PDF, настройки и папки сохраняются; перенос покрыт отдельным тестом. Штрихи — векторные точки с координатами документа, давлением, временем и доступным наклоном. Масштаб интерфейса и поворот страницы не переписывают координаты.

После каждого законченного штриха, стирания или изменения документ сразу передаётся в последовательную очередь IndexedDB — таймера и кнопки «Сохранить» нет. Статус «Все изменения сохранены» появляется только после завершения транзакций. Для записи запрашивается строгая долговечность (`durability: strict`). При ошибке доступны повтор сохранения и выгрузка копии. В одной транзакции текущая корректная версия переносится в `previous`, затем записывается новая. Некорректная структура отклоняется. При чтении повреждённого документа восстанавливается предыдущая корректная версия. Интерфейс сообщает об ошибках и позволяет скачать данные из памяти. Закрытие вкладки при незавершённой записи вызывает предупреждение браузера, когда он это поддерживает.

В настройках можно запросить постоянное хранение браузера. Оно не заменяет резервные копии. Не используйте приватный режим для постоянных конспектов и не очищайте данные сайта без экспорта. Два одновременно редактирующих окна одного документа могут перезаписать изменения друг друга: синхронизации между окнами нет.

Резервная копия — JSON-контейнер `.darknotes`, версия 1, с векторными документами и исходными PDF в data URL. Импорт объединяет библиотеку; совпадающие ID заменяются, предыдущая версия документа сохраняется. Настройки из копии также восстанавливаются. Формат не зашифрован.

## Архитектура

| Модуль | Назначение |
| --- | --- |
| `src/model.ts` | Схема документов, объектов, страниц, папок и настроек |
| `src/storage.ts` | Dexie/IndexedDB, проверка данных, очередь сохранений, предыдущие версии, копии |
| `src/engine/geometry.ts` | Геометрия, произвольное лассо, пересечения, пространственный индекс, стирание, распознавание жестов |
| `src/engine/InkEngine.ts` | Единый автомат состояний Pointer Events, активный штрих, навигация, удержание и выделение |
| `src/engine/render.ts` | Кэш Path2D, контуры perfect-freehand, бумага, текст и изображения |
| `src/engine/history.ts` | Undo/Redo в рабочей сессии |
| `src/pdf.ts` | Локальный PDF.js Worker, текстовый слой, поиск, импорт |
| `src/export.ts` | Векторный PDF, цветовые профили, шрифты и перенос исходных страниц |
| `src/appearance.tsx` | Общая тема, парные палитры, адаптация бумаги и PDF |
| `src/components/PageView.tsx` | Отдельные PDF/бумажный, сохранённый и активный слои, миниатюры |
| `src/components/Editor.tsx` | Редактор, страницы, виртуализация, масштаб, горячие клавиши |
| `src/components/Library.tsx` | Файловый менеджер и дерево папок |
| `src/components/FileMenu.tsx` | Доступные меню файлов на Radix UI |
| `src/components/FloatingToolbar.tsx`, `ToolPopover.tsx` | Плавающая панель и расположение меню в границах экрана |
| `src/components/Settings.tsx` | Ввод, редактор, оформление, копии и установка |
| `src/styles.css`, `src/editor.css` | Общие токены и компактный интерфейс редактора |
| `vite.config.ts` | Сборка, базовый путь, manifest и кэширование PWA |

Статичные чернила и незавершённый штрих рисуются раздельно. Ввод использует `requestAnimationFrame`, `devicePixelRatio`, Pointer Events и доступные `getCoalescedEvents()`. Предсказанные точки намеренно не добавляются в сохраняемые данные. При `pointercancel` незавершённый жест отменяется.

## Проверки

```sh
npm test
npm run build
npm run test:e2e
```

38 модульных проверок охватывают геометрию, ложные срабатывания на математических символах, частичное стирание, историю, последовательные записи, папки, корзину, повреждённые данные и восстановление копий.

21 браузерный тест Playwright запускают production-сборку в установленном Microsoft Edge. Сценарии включают запись с перезагрузкой, оба варианта Circle to Lasso, реальные координаты перемещения, Scribble to Erase с отменой, папки, PDF, текстовый слой, поворот и экспорт, мобильный интерфейс, синтетический двухпальцевый ввод, `pointercancel`, офлайн-сохранение и обратный импорт проектов. Дополнительно проверяются положение панели после перезагрузки и поворота, перетаскивание пальцем без штрихов, сохранение давления/наклона пера, отменённое касание ладони и повтор записи после ошибки квоты. Скриншоты и диагностические файлы создаются в `test-results`.

Два дополнительных теста запускаются в WebKit с мобильным режимом и планшетным экраном: письмо, отмена/повтор, панель, поворот, офлайн, импорт PDF, поиск, проектный бэкап и векторный экспорт. Установка и запуск:

```sh
npx playwright install webkit
npm run test:webkit
```

Если Edge не установлен, установите его либо замените `channel` в `playwright.config.ts` на доступный Chromium и выполните `npx playwright install chromium`.

## Проверка на настоящем iPad / Apple Pencil

Пройдены проверки WebKit с эмуляцией планшета и синтетического пера в Chromium. Аппаратное поведение Apple Pencil и Safari на настоящем iPad **не проверено**: эмуляция не подтверждает фактическую задержку и отсечение ладони на устройстве.

1. Откройте HTTPS-версию в Safari, дождитесь сообщения об офлайн-готовности. Добавьте приложение на экран «Домой» и откройте из иконки.
2. Создайте A4-тетрадь в клетку, включите «Рисовать только стилусом». Напишите `∫₀¹ x² dx`, дробь, `Σ`, индексы, `α`, стрелку. Проверьте отсутствие ошибочного стирания.
3. Напишите несколько линий с разным нажимом, быстро нарисуйте длинную синусоиду, положив ладонь на экран. Проверьте толщину, непрерывность и отсутствие случайных штрихов от ладони. Сравните с выключенной чувствительностью к давлению.
4. Обведите формулу и удержите конец контура 650 мс. Переместите выделение и отмените перемещение. Повторите с отрывом пера и повторным удержанием нарисованного контура.
5. Нарисуйте обычный круг без паузы — он должен остаться чернилами. Затем удержите после рисования линии — она должна выпрямиться.
6. Быстро зачеркните один ошибочный знак шестью или более проходами. Соседние записи должны остаться; отмена возвращает знак. Медленную штриховку не следует удалять.
7. Выполните щипок и перемещение двумя пальцами. Новые штрихи появляться не должны. Во время активного письма касания ладони должны игнорироваться настолько, насколько позволяет браузер.
8. Импортируйте многостраничный PDF, отметьте формулу маркером, увеличьте страницу, поверните её и экспортируйте. Сравните расположение аннотаций в системном просмотрщике PDF.
9. Включите авиарежим, закройте и снова откройте установленное приложение. Продолжите запись. Перезапустите — изменения должны сохраниться.
10. Сохраните копию библиотеки в приложение «Файлы» и восстановите её в другом профиле браузера. Проверьте исходные PDF, папки, рисунки и текстовые блоки.

## Ограничения

- Это самостоятельный браузерный редактор; аппаратные функции Goodnotes и Apple Pencil, включая double-tap/squeeze стилуса, не эмулируются.
- Полная palm rejection не гарантируется: веб-приложение использует типы указателей, режим «только стилус» и игнорирует touch во время активного pen-ввода.
- Распознавание жестов эвристическое. Отключите Scribble to Erase для плотной быстрой штриховки, если она похожа на команду стирания. Масштаб выделения доступен с шагом 15%; свободного вращения отдельных объектов нет.
- Если при экспорте нужно изменить цветовую тему **исходного PDF**, его фон растрируется с коэффициентом 2; текстовый слой этого фона в таком экспорте теряется. Штрихи и добавленные текстовые блоки остаются векторами. При сохранении исходной темы фон PDF переносится векторно. Для дальнейшего редактирования в DarkNotes используйте `.darknotes`.
- Смена темы PDF оценивает яркость по краям страницы. Цветные иллюстрации внутри перекрашиваемого PDF могут менять оттенки. Отдельно вставленные картинки сохраняют исходные цвета. Неподдерживаемые встроенным шрифтом символы заменяются квадратом.
- Без текстового слоя PDF поиск и копирование печатного текста недоступны. Рукопись не распознаётся и не индексируется.
- Предпросмотр PDF использует локальные ресурсы, без CDN. Импорт ограничен 250 МБ, изображение — 15 МБ, копия — 500 МБ; фактическая вместимость зависит от памяти и квоты браузера. Восстановление копии читает JSON в память.
- История хранится в памяти на протяжении рабочей сессии, до 80 изменений. После перезагрузки документа его содержимое сохраняется, история отмен — нет.
- Service Worker и установка требуют HTTPS или localhost. По обычному HTTP с другого устройства полноценная PWA не работает. Установка на iPad выполняется вручную через меню Safari.
- Внешняя синхронизация, совместное редактирование, аудиозапись и распознавание текста отсутствуют.

## Отдельная публикация на GitHub Pages

Репозиторий: [BelovVlad/DarkNotes](https://github.com/BelovVlad/DarkNotes). Адрес приложения: [DarkNotes](https://belovvlad.github.io/DarkNotes/). Изменения в `main` автоматически публикуются через GitHub Actions. Проект размещён отдельно от основного сайта.

1. Используйте уже настроенный `origin` — `https://github.com/BelovVlad/DarkNotes.git`. `.tools`, `node_modules`, `dist`, `public/pdf` и тестовые артефакты исключены через `.gitignore`.
2. В Settings → Pages выберите Source: **GitHub Actions**.
3. Отправьте изменения в ветку `main`. Готовый `.github/workflows/deploy.yml` установит зависимости по lock-файлу, выполнит модульные тесты, соберёт приложение и опубликует `dist`.
4. Базовый путь автоматически задаётся как `/<имя-репозитория>/`. Для репозитория `DarkNotes` адрес будет `https://<пользователь>.github.io/DarkNotes/`.

Для ручной сборки под вложенный путь в PowerShell:

```powershell
$env:BASE_PATH = '/DarkNotes/'
npm run build
Remove-Item Env:BASE_PATH
```

Для собственного домена используйте `BASE_PATH=/`. Маршруты внутри приложения используют `#`, поэтому обновление страницы редактора не требует серверных перенаправлений. Подготовка PDF-ресурсов выполняется автоматически до сборки и dev-запуска. Подход к `base` и Pages соответствует [официальной инструкции Vite](https://vite.dev/guide/static-deploy.html#github-pages).

Данные привязаны к origin браузера, а не к адресу папки в Pages. Приложения на одном `*.github.io` могут разделять origin; имена базы и кэша DarkNotes отдельные, но перед обновлениями других приложений на этом домене сохраняйте резервную копию.
